# Mock.er

Client-side 3D jersey mockup generator for teamwear designers. Upload flat artwork, orbit a UV-mapped jersey in the browser, export angles as PNG.

Product requirements: [docs/PRD.md](docs/PRD.md). Technical spec: [docs/SPEC.md](docs/SPEC.md).

## Development

```bash
npm install
npm run dev
```

```bash
npm run build
npm start
```
